# 天关13（Tianguan13 / SS13）药物代谢与伤势模拟器

一款面向 **天关13（Tianguan13）** 医疗与化学玩家的交互式试药台。无需进服拿船员做临床实验，在浏览器中即可推演各类给药方案的疗效、过量风险与生理演化。

## 核心功能

- **多药配伍与全程曲线**：自由组合药物并设定剂量、纯度、给药时机与途径（注射、口服、贴片、静脉滴注、接触、蒸气）；支持将多药合装入单张 `≤40u` 合并贴片（按含量比例共享 `0.75u/tick` 缓释与一键自动合片），实时查看生命值、五维伤势、血药/胃药浓度、器官损伤及体温血量变化。
- **场景 URL 分享与基准对比**：支持将完整患者状态、过敏配置、给药组合及模拟参数编码为 `#s=...` 链接一键分享与导入复现，并支持固定基准曲线直观对比调整前后疗效。
- **医疗风险与特殊体质**：完整模拟过量（OD）、低纯度逆产物、体内禁忌反应、不同肝脏型号与器官衰竭，以及「极端药物过敏」和「化学过敏」体质的发作与肾上腺素阻断。
- **药品图鉴与多维筛选**：支持按官方汉化译名与 Wiki 常用别名检索，并可按「无过敏」「无过量」「有逆反应」「死后生效」「治疗目标」等特征组合筛选。
- **方案存档与配方导出**：支持本地保存常用给药组合与 JSON 导入导出，并提供菜谱式纯文本配方导出（自动合并同时间 `≤40u` 贴片与 `≤50u` 口服药丸，支持多行配制清单 / 单行紧凑格式一键复制与 `.txt` 下载）。

## 常见使用场景

- **化学配药验证**：设计多合一药丸、缓释贴片或急救针配比，确认回血效率、OD 安全余量与肝肾负荷。
- **高压抢救演练**：在濒死重危、失血、着火、冷冻仓、静滞或药物过敏等状态下，测试最优给药顺序与补药窗口。
- **新人药理上手**：直观理解天关13 药物的代谢节奏、纯度影响与禁忌搭配，减少实战中的意外医疗事故。

## 快速开始

请确保本地已安装 [Bun](https://bun.sh/)：

```bash
# 安装依赖
bun install

# 启动本地开发服务器
bun run dev
```

### 常用命令

```bash
# 运行单元测试（Vitest）
bun run test

# TypeScript 类型检查
bun run typecheck

# 生产构建（输出至 dist/）
bun run build

# 预览生产构建产物
bun run preview
```
